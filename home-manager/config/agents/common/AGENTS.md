# Глобальные правила

## Стиль письменных текстов

Когда составляешь письмо, сообщение, пост, заметку или любой другой текст от имени пользователя, используй только обычные символы, которые люди обычно набирают с клавиатуры.

**ЗАПРЕЩЕНО:**
- Использовать длинные тире и другие типографские варианты тире вместо обычного дефиса `-`
- Использовать косые или типографские кавычки вместо обычных прямых кавычек `"` и `'`
- Использовать смайлы, эмодзи и декоративные символы
- Добавлять любые редкие типографические символы, которые выглядят как сгенерированный или специально оформленный текст

**ПРАВИЛЬНО:**
- Писать естественно и просто, как человек набирает текст вручную
- Использовать обычный дефис `-`, прямые кавычки `"` и `'`, стандартные знаки препинания

## Git и управление изменениями

### КРИТИЧЕСКИ ВАЖНО: Никогда не коммить изменения автоматически!

**ЗАПРЕЩЕНО:**
- Выполнять `git commit` без явного разрешения пользователя
- Автоматически создавать коммиты в процессе работы
- Самостоятельно принимать решения о коммитах
- Говорить "изменения готовы к коммиту" или предлагать коммит

**ПРАВИЛЬНО:**
- Только подготавливать изменения (`git add`) если попросили
- Ждать явной команды от пользователя
- Никогда не упоминать коммиты первым

### КРИТИЧЕСКИ ВАЖНО: Никогда не откатывать изменения через git!

**ЗАПРЕЩЕНО:**
- Выполнять `git restore` или `git checkout` для отката файлов
- Использовать `git reset` для отмены изменений
- Откатывать изменения через git при ошибках в коде
- Удалять частично работающий код через git команды

**ПРАВИЛЬНО:**
- Исправлять ошибки редактированием кода
- Сохранять частично работающий код
- Спросить пользователя если нужен откат изменений
- Использовать Edit tool для исправления ошибок

### Пример правильного подхода:
```bash
# ДОПУСТИМО - только если попросили
git add .
git status

# ЗАПРЕЩЕНО - автоматический коммит
git commit -m "..."

# ЗАПРЕЩЕНО - предложение коммита
"Изменения готовы к коммиту. Хотите создать коммит?"

# ЗАПРЕЩЕНО - откат изменений при ошибке
git restore src/file.cs
git checkout -- src/file.cs

# ПРАВИЛЬНО - просто молчать
[пользователь сам решит когда делать коммит]

# ПРАВИЛЬНО - исправить ошибку редактированием
[использовать Edit tool для исправления проблемы]
```

**Принцип:** Git история принадлежит пользователю. Агент молчит о коммитах пока не спросят.
