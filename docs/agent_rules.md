# Правила для агента

## Папка `hidden`

Никогда не заходи в папку `hidden` и не читай ее содержимое. Это главное правило репозитория.

Запрещено:

- открывать файлы из `hidden`;
- выводить содержимое файлов из `hidden`;
- рекурсивно обходить, индексировать или искать по `hidden`;
- выполнять команды, которые могут неявно прочитать содержимое `hidden`;
- изменять, перемещать или удалять файлы в `hidden`.

Если для задачи требуется информация из `hidden`, спроси ее только у пользователя. При необходимости можно отдельно запросить разрешение на получение имен файлов в `hidden`, но не их содержимого. До явного ответа пользователя считай содержимое папки недоступным.

## Работа с конфигурацией

- Перед изменениями прочитай [архитектуру репозитория](architecture.md) и используй ее точки подключения.
- Новые NixOS-модули подключай через `nixos/configuration.nix`; модули Home Manager - через `home-manager/home.nix`.
- Не добавляй секреты, учетные данные и локальные данные в отслеживаемые файлы. Для локальных данных предназначена недоступная агенту папка `hidden`.
- После изменения Nix-файлов проверяй конфигурацию безопасной для задачи командой, не затрагивающей `hidden`.
