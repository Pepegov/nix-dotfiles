# Дизайн системы

## Общее направление

Интерфейс построен на темной природной палитре Alacritty, которая является базой для всей системы. Почти черный теплый фон создает спокойную основу, несколько оттенков зеленого формируют уровни поверхностей и рабочие состояния, а кремовый текст сохраняет читаемость без резкого белого контраста. Золотистый акцент выделяет активные и интерактивные элементы.

Стиль минималистичный и функциональный: интерфейс не перегружен декоративными деталями. Основные визуальные признаки системы - скругленные контейнеры, тонкие границы, компактные отступы и моноширинный шрифт JetBrainsMono Nerd Font.

## Компоненты

### Polybar

Главная панель имеет зеленый фон #17271C, скругление 14 px и тонкую коричневую рамку #5C4939. Акцентная линия и подчеркивания модулей используют #D2B77C. Активный рабочий стол получает более светлый зеленый фон #2B452F, яркий текст и золотистое подчеркивание. Срочное рабочее пространство выделяется терракотовым #C17C5D с темным текстом.

### Rofi

Окно запуска приложений имеет темно-зеленую поверхность #17271C, золотистую рамку толщиной 2 px и скругление 14 px. Поле поиска выполнено на почти черном фоне #0D0C07 и отделено тонкой границей дополнительной зеленой поверхности #203828.

Элементы списка по умолчанию используют приглушенный текст. Выбранный пункт получает оливковый фон #39462B и яркий кремовый текст. Активные кнопки используют ту же оливковую поверхность, а их текст становится золотистым.

### Alacritty

Терминал является основным источником семантики цветов для остальных компонентов системы. Его фон #0D0C07 и основной текст #E4D1A6 используются как базовая пара во всем окружении. Курсор и выделение выполнены в золотистом #D2B77C с темным текстом, поэтому текущая точка ввода и выделенный фрагмент остаются заметными без холодных контрастных оттенков.

Терминальная ANSI-палитра продолжает общий зеленый характер: `green` - #8EA06B для успеха, `magenta` - #39462B и `cyan` - #2B452F для зеленых состояний и уровней, `blue` - #B29570 как спокойный вторичный акцент. Красный #C17C5D остается цветом ошибки, желтый #D2B77C - цветом внимания. Нижняя панель терминала использует #203828, связывая терминал с дополнительными поверхностями Rofi и Polybar.

## Типографика и ритм

Основной шрифт - `JetBrainsMono Nerd Font`. В Rofi используется размер 13 px, в основной панели Polybar - 14 px. Моноширинный шрифт поддерживает технический характер окружения и корректное выравнивание значков Nerd Font.

Скругления задают мягкий силуэт: 14 px для крупных контейнеров, 7-9 px для полей и кнопок. Внутренние отступы компактные: около 7-18 px в зависимости от размера элемента. Между элементами Rofi используется свободное пространство 5-14 px, чтобы список и поле поиска оставались визуально раздельными.

## Правила применения

- Использовать #0D0C07 для глубокого фона и вложенных областей.
- Строить уровни интерфейса от #17271C к #203828, не заменяя поверхности нейтральным серым.
- Сохранять семантику Alacritty: #8EA06B для успеха, #C17C5D для ошибки и #D2B77C для фокуса или внимания.
- Оставлять #D2B77C цветом фокуса и ключевого действия, не применять его для больших фоновых областей.
- Использовать яркий текст только для текущего выбора, ввода и наиболее важной информации.
- Для обычных подписей и второстепенных данных выбирать #A99A7C, чтобы сохранить иерархию.
- Применять #C17C5D только для ошибок, срочных состояний и предупреждений, требующих действия.
